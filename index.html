Raven B4 → Opal

Paste a Raven B4 script and get a single-file Opal extension for Minecraft 26.2. The output bundles a compatibility layer that implements Raven's client, modules, render, world, keybinds, util, inventory and gl objects on top of Opal. Text option sliders become mode settings, and gl drawing runs through Opal's mesh renderer.
